# MindNest V2 assets — sources and licences

## Art (`storybook-classic/`, `*/bg.jpg`, `*/characters.png`, `storybook-classic/fable-1/`)
AI-generated for this project (image-generation model, Nov 2026), using the Storybook Classic character sheet
(`storybook-classic/characters.png`) as the identity reference for every pose. Character cut-outs were generated on a
chroma-green background, keyed to alpha and despilled; plates are 768x1376 JPEG, cut-outs WebP with alpha.
Licence note: under the image tool's terms the user owns the outputs, but purely AI-generated images may not be
protectable by copyright in some jurisdictions (e.g. US Copyright Office guidance), so others could reuse them.

## Fonts (`fonts/`) — SIL Open Font License 1.1 (licence text next to each family)
- Baloo 2, Baloo Bhaijaan 2 — Ek Type (`OFL-baloo-2.txt`, `OFL-baloo-bhaijaan-2.txt`)
- Mukta — Ek Type (`OFL-mukta.txt`)
- M PLUS Rounded 1c — The Rounded M+ Project Authors (`OFL-m-plus-rounded-1c.txt`); subset to Latin, kana, CJK
  unified ideographs, CJK punctuation, full-width forms (fontTools), WOFF2.
- Noto Sans KR — Adobe / Google (`OFL-noto-sans-kr.txt`); variable font instanced at wght 500 / 800 and subset to
  Latin, Hangul jamo + syllables, CJK punctuation, full-width forms, WOFF2.
Source: github.com/google/fonts (ofl/mplusrounded1c, ofl/notosanskr).

## Music (`audio/music-box-loop.mp3`)
Original, synthesised from sine partials by `scripts/sound/synth_mindnest_v2.py` (music-box lullaby in D major
pentatonic over a soft pad, 40 s seamless loop). No samples or third-party recordings: no licence needed.
No CC0 / public-domain track was used.

## Sound effects
`public/sfx/swoosh.mp3` and `public/sfx/bell.mp3`: original synthesised sounds already in the repo (`scripts/sound/`).

## Narration (`audio/fable-<n>/<lang>/`)
Kokoro-82M (Apache-2.0) via kokoro-onnx, voices from `channels/voices.ts` (Hindi `hf_alpha`, Spanish `ef_dora`,
speed 0.92), generated by `scripts/mindnest-v2-voice.ts`. `episode.json` records the engine actually used.
