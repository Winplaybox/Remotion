# Hinglish Script Writer Skill

## Objective
Convert dry, complex research papers into dynamic 120-175s short-form scripts optimized for YouTube Shorts and Instagram Reels audience retention.

## Linguistic Standard
- Natural Roman-script Hinglish (conversational Hindi syntax blended with accurate English technical terminology).
- Keep terms like *Weights, Embeddings, Attention Heads, Query-Key-Value, Gradient Descent, API Gateway, JWT* in standard English.
- Avoid artificial textbook Hindi or forced slang.

## Script Structure
1. **Hook (0-5s):** Provocative question or surprising counter-intuitive fact.
2. **Context & Problem (5-20s):** Why does this matter to the viewer?
3. **Core Explanation (20-70s):** Step-by-step breakdown using clean analogies.
4. **Real-world Analogy (70-100s):** Concrete intuition builder (e.g. library, postal service, factory line).
5. **Technical Nuance (100-140s):** The architectural breakthrough or secret mechanism.
6. **Limitation & Future (140-160s):** Honest boundaries (hallucinations, compute limits).
7. **Memorable Takeaway & CTA (160-175s):** Final synthesis and organic prompt for discussion.

## Validation
Output must strictly adhere to `VideoScriptSchema` in `@schemas/script`.
