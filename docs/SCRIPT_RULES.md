# Script rules for narrated Shorts (Jasoos Bhai, Gemini prompts)

Adapted from the `faceless-shorts` skill (original writing only — never copy another creator's script or shots).

1. **Talk like a person to a friend**: flowing sentences with connectors ("Lekin", "toh", "matlab"), not a list of caption-like statements. ~90–110 words for 35 s.
2. **A line is a CUT, not a sentence**: split a sentence into 1–3 lines at natural pauses so the picture changes every 1.5–3.5 s while the voice keeps flowing.
3. **Shape**: hook question → escalation → myth or surprise → twist → punchy last line that loops back to the hook.
4. **Numbers as they are said** (Hindi voices: words in Devanagari, no digits).
5. **Facts checked** against a reliable source; keep sources in the job record.
6. **QA before publishing**: contact-sheet of frames; each frame must make sense, match its narration beat, nothing colliding with the caption zone, one highlighted word per caption, voice clear over music.
7. **Retention**: first 2 s must stop the scroll (question, number, shock); end by asking for the answer in the comments (Jasoos: "1 / 2 / 3 likho").
